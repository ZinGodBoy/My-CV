# Tạ Đăng Khôi — My-CV

> **Personal CV & Portfolio Website** của **Tạ Đăng Khôi**, sinh viên ngành Công nghệ Thông tin, định hướng phát triển theo lĩnh vực **Full-Stack Development, Web Development và UI/UX Design**.

---

## 👤 Giới thiệu dự án

**My-CV** là website CV và Portfolio cá nhân của **Tạ Đăng Khôi**, được xây dựng nhằm giới thiệu thông tin cá nhân, định hướng nghề nghiệp, kỹ năng công nghệ, các dự án đã thực hiện và thông tin liên hệ.

Website được phát triển theo hướng:

- Hiện đại.

- Tối giản.

- Responsive.

- Dễ sử dụng.

- Tương thích Desktop, Tablet và Mobile.

- Có khả năng mở rộng trong tương lai.

Dự án đồng thời là sản phẩm thực hành nhằm áp dụng kiến thức về **HTML, CSS, JavaScript, UI/UX, Git và GitHub** vào một sản phẩm thực tế.

---

# 🐳 Chạy bằng Docker

## Yêu cầu

Cài:

- Docker Desktop trên Windows/macOS.

- Docker Engine trên Linux.

Kiểm tra Docker:

```bash

docker --version

```

---

## Tạo Dockerfile

Tạo file:

```text

Dockerfile

```

Nội dung:

```dockerfile

FROM nginx:alpine

COPY . /usr/share/nginx/html

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]

```

---

## Build Docker Image

```bash

docker build -t ta-dang-khoi-cv .

```

## Chạy Container

```bash

docker run -d -p 8080:80 --name ta-dang-khoi-cv ta-dang-khoi-cv

```

Truy cập:

```text

http://localhost:8080

```

## Kiểm tra Container

```bash

docker ps

```

## Dừng Container

```bash

docker stop ta-dang-khoi-cv

```

## Xóa Container

```bash

docker rm ta-dang-khoi-cv

```

---

# 🐳 Docker Compose

Tạo file:

```text

compose.yaml

```

Nội dung:

```yaml

services:

  web:

    build: .

    container_name: ta-dang-khoi-cv

    ports:

      - "8080:80"

    restart: unless-stopped

```

Khởi động:

```bash

docker compose up -d --build

```

Truy cập:

```text

http://localhost:8080

```

Dừng:

```bash

docker compose down

```
